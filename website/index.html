大象从不遗忘。把会议录音变成可带走的纪要——录制或导入音频，自动转写，整理出要点、待办与决策。

Features

开会只管说，纪要交给大象

从录音到可分享的纪要，Meetphant 把每一步都做得简单、可控。

01 / 03

独立录制，不被会议平台绑定

同时录制麦克风与系统声音。腾讯会议、飞书、Zoom、Teams，还是线下会议室，都能一键开录。

  • 麦克风与系统声音双轨电平实时可见，录没录上一眼便知
  • 不依赖任何会议软件的插件、机器人或会议权限
  • 已有录音？直接导入 wav、mp3、m4a 等本地音频
02 / 03

自定义热词，越用越懂你

把专有名词、人名、产品名加入热词表，转写时随请求一并提交给识别引擎，结果更准。

  • 同事姓名、客户名称、项目代号，一次添加长期生效
  • 热词只作用于转写；摘要另有「上下文」设置提供背景信息
  • 发言人可重命名，纪要里直接显示真实称呼
03 / 03

可连接本地大模型，纪要由你做主

摘要支持任意 OpenAI 兼容接口：可以选用云端服务，也可以填写自定义 Base URL，连接本机 Ollama 或公司内网部署的模型。

  • 自定义端点，例如 http://localhost:11434/v1
  • 连接本地模型时，生成摘要不必把会议内容交给第三方 AI 服务
  • API Key 只存入系统钥匙串，不写入数据库，也不会回显明文

说明：语音转写目前使用云端的豆包录音文件识别 2.0，音频需经你自己的火山引擎 TOS 存储桶上传。

How it works

三步，从录音到纪要

  1. STEP 01

    录制或导入

    开会时一键录下麦克风与系统声音，或导入已有的会议音频。

  2. STEP 02

    自动转写

    停止录音即自动建会并转写，区分发言人，热词让专有名词更准确。

  3. STEP 03

    生成摘要

    一键整理要点、待办与决策，支持中文、英文或双语，复制即可分享。
